## 원칙 (반드시 지킬 것)

- 검증은 프롬프트가 아니라 **스크립트가** 한다. 스크립트가 중단하면 따르고 우회하지 말 것.
- 시크릿 값을 출력하거나 요약에 쓰지 말 것.

## 1) 클로브에서 승인내역 조회
1. `get_my_context` → **(주)로가** companyId (businessRegNo 1768101964, 보통 `31CbqJ82UGIZTXzfKRPd2`). (주)로가JHT·로가온은 대상 아님.
2. `get_card_approvals` 로 조회한다. **조회 창은 요일에 따라 다르다**:
   - **월요일: 60일** (되짚기 스윕)
   - **화~금: 14일**
   `startDate`=그만큼 이전, `endDate`=오늘, `size`=100
3. 응답의 `hasNext` 가 true 면 `page` 를 1씩 올려 **끝까지** 모두 받는다. (한 페이지라도 빠지면 스크립트가 건수 불일치로 중단)
4. `get_scraping_status` 로 CARD_APPROVAL 자산의 `scrapedAt` 확인. 수집이 어제보다 이전이면 **적재하지 말고** 사실만 남기고 종료.

커넥터 조회가 안 되면 아무것도 하지 말고 사유만 남기고 종료.

⚠⚠ **조회 창이 왜 3일이 아니라 14/60일인가 (2026-09-11 원인 규명)**
종전에는 3일이었는데 **9월 절반(68건 546만원)이 조용히 빠졌다.** 태스크는 매일 정상 실행됐다.
원인은 **해외 결제가 며칠 늦게 들어오는 것**이었다 — 9/2~9/3 누락 55건 343만원이 대부분
방콕 출장 현지 결제(GRAB·QSNCC 등)였고, 원화 금액이 확정될 때쯤엔 이미 3일 창이 지나갔다.
같은 일이 7월에도 있었다(42건 1,648만원, 전부 해외 — FACEBK 메타 광고비 등).
→ 창을 넓히면 재적재로 자동 복구된다. 중복은 approval_id 로 차단되고, **금액이 달라진 건은
  갱신되고 취소된 건은 삭제된다**(Edge 가 amended/removed 처리). 넓게 봐도 손해가 없다.

## 3) 검증 → 적재
```bash
cd "C:/Users/RAWGA/Downloads/rawga-dashboard-git"
node scripts/clobe-card-ingest.mjs "C:/Users/RAWGA/AppData/Local/Temp/clobe-card-YYYYMMDD.json" --dry-run
```
스크립트가 하는 일: approvalId 중복 제거 · totalElements 대조 · **취소건(순액 0) 분리** · 오늘자 제외 · 카드번호→별칭 매핑(`scripts/card-alias-map.json`) · memo 에서 계정과목 추출(':' 앞) · 월별 요약 출력.

당일분은 제외한다(`--allow-today` 를 붙이지 말 것). 이유: '가승인' 류는 몇 시간 뒤 전액취소되는 일이 잦아 당일 사용액이 과대계상된다. 하루 지나면 취소가 반영된 순액으로 들어온다.

검증에서 중단(exit 2)이나 **별칭 미매핑 경고**가 나오면 적재하지 말고 요약에 남긴다.
문제 없으면 `--dry-run` 없이 실행해 적재한다. 중복은 approval_id + 복합키로 이중 차단되므로 재실행해도 안전하다(수기 엑셀 업로드분과도 안 겹침).

**출력의 `금액 갱신 N건` 은 정상이다** — 해외 결제 원화 확정액이 늦게 와서 바뀐 것이다. 다만 '전 → 후' 목록을 요약에 남긴다. 이미 적재된 과거 숫자가 바뀌는 일이라 사람이 알아야 한다. 국내 건이 바뀌면 이상 신호다.

**`취소 삭제 N건` 도 요약에 남긴다.** 적재 후 취소된 건을 지운 것이며 과거 사용액이 그만큼 줄어든다. 되돌릴 수 없으므로 삭제 목록을 반드시 남길 것.

## 3-1) 적재 후 대조 (필수 — 조용한 누락을 잡는 유일한 장치)
```bash
node scripts/card-ingest-verify.mjs "C:/Users/RAWGA/AppData/Local/Temp/clobe-card-YYYYMMDD.json"
```
방금 저장한 **같은 파일**을 그대로 넘긴다. approval_id 기준으로 ①누락 ②금액 불일치 ③유령을 보고하고, 불일치가 있으면 exit 1 한다.

⚠ **왜 필요한가**: 적재 스크립트는 한 달을 통째로 놓쳐도 "추가 N · 중복 skip M" 을 찍고 정상 종료한다. 2026-07 에 42건 1,648만원이 빠진 걸 비씨 8/23 청구서(18,544,957) 와 예정 추정(2,048,614) 이 9배 차이나서야 발견했다. 이 대조가 그걸 당일에 잡는다.

⚠ **오늘자 누락은 정상이다** — 당일분 제외 규칙 때문이다. 누락 목록의 날짜가 전부 오늘이면 통과로 본다.
⚠ '유령(우리에만)' 은 수기 엑셀 업로드분(정상)이거나 적재 후 취소분이다. 후자는 이제 3)에서 자동 삭제되므로, 그래도 남으면 조사 대상이다.
